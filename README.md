# Profile Card With Hover

Projeto desenvolvido para praticar a criação de interfaces modernas utilizando HTML e CSS, com foco em efeitos hover, animações e estilização de componentes.

## 🚀 Objetivo

O principal objetivo deste projeto foi aprimorar habilidades em desenvolvimento front-end através da construção de um cartão de perfil interativo e visualmente agradável.

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3

## ✨ Funcionalidades

- Efeito hover animado
- Design moderno
- Estrutura responsiva
- Animações suaves
- Estilização personalizada

## 📚 Conceitos praticados

- Flexbox
- Transições CSS
- Hover effects
- Posicionamento de elementos
- Responsividade
